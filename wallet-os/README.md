# WALLET OS

منصة إدارة مالية شخصية عربية تعمل كتطبيق ويب تقدمي (PWA)، متصلة بمشروع Supabase مخصص وتُنشر على Vercel.

## المكونات

- واجهة عربية RTL مع وضع فاتح/داكن وتصميم متجاوب.
- تسجيل دخول وإنشاء حساب عبر Supabase Auth.
- إدارة العمليات والحسابات والادخار والتمويلات والأقساط والاستثمارات والميزانيات والتقارير.
- مساعد مالي يدعم إعداد مفتاح API من داخل الإعدادات.
- أسعار صرف مرجعية، أسعار الذهب، وأسعار سوق الأصول مع حفظ سجل الأسعار في Supabase.
- تثبيت على شاشة الهاتف كتطبيق PWA من المتصفح.

### مخطط التخزين

- `profiles`, `transactions`, `accounts`, `savings_goals`, `liabilities`, `investments`, `budgets`, `financings`, `financing_payments`: بيانات مالية مرتبطة بهوية Supabase Auth.
- `exchange_rates`: الأسعار المرجعية أو اليدوية التي يعتمد عليها حساب المستخدم.
- `market_fx_snapshots`: سجل تاريخي لأسعار الصرف مع نوع السعر والمنطقة والمصدر والتاريخ.
- `gold_price_snapshots`: سجل السعر الفوري للذهب بالدولار للأونصة الترويسية مع وقت الرصد والمصدر.
- `market_asset_quotes`: سجل أسعار المعادن والعملات الرقمية والأسهم مع رمز الأصل ومصدر السعر ووقت الرصد.
- `private.user_ai_provider_configs`: بيانات إعداد مزود الذكاء الاصطناعي ومعرّف السر فقط؛ لا يخزن المفتاح كنص مكشوف.

جميع جداول البيانات المالية وأسعار السوق الشخصية لها RLS مع شرط `auth.uid() = user_id`. جدول إعدادات المزوّد موجود في schema غير مكشوفة للـ Data API، ومقفل بالصلاحيات وRLS.

### مفاتيح الذكاء الاصطناعي

من التطبيق: الإعدادات ← إعداد الذكاء الاصطناعي:
1. اختر Ollama Cloud أو OpenAI أو OpenRouter أو Groq أو مزودًا مخصصًا متوافقًا مع OpenAI.
2. أدخل اسم النموذج ومفتاح API.
3. عند اختيار مزود مخصص أدخل عنوان HTTPS الأساسي.
4. اضغط حفظ، ثم اختبر الاتصال.

يُرسل المفتاح مرة واحدة إلى خادم WALLET OS عبر HTTPS ثم يُحفظ في Supabase Vault المشفر. عند المحادثة يستخرج الخادم المفتاح المرتبط بالمستخدم الحالي فقط؛ لا يُعاد المفتاح إلى واجهة المتصفح ولا يُكتب في `localStorage` أو GitHub. اترك حقل المفتاح فارغًا عند تحديث اسم النموذج فقط، وأدخل مفتاحًا جديدًا عند تغيير المزوّد.

متغيرات Ollama القديمة على Vercel تبقى خيارًا احتياطيًا فقط عندما لا يضبط المستخدم مزودًا شخصيًا:
- `OLLAMA_BASE_URL`
- `OLLAMA_MODEL`
- `OLLAMA_API_KEY` (Sensitive)

### بيانات السوق والصرف والذهب

- أسعار الصرف الآلية عبر Frankfurter هي أسعار مرجعية يومية (mid-market)، وليست سعر الصراف أو السوق النقدي المحلي في اليمن.
- أسعار YER المحلية يمكن إدخالها يدويًا من الإعدادات، وتحفظ مع `rate_type=manual` والمنطقة YEMEN، ولا تُعرض على أنها سعر رسمي أو سعر سوق تم التحقق منه.
- سعر الذهب XAU يجلب من Gold API بالدولار للأونصة الترويسية، ويُحفظ في `gold_price_snapshots`. السعر لا يشمل المصنعية أو الضرائب أو هامش التاجر.
- الأسعار المعدنية والعملات الرقمية والأسهم التي يسترجعها التطبيق تُسجل في `market_asset_quotes` مع المصدر والوقت. بعض المصادر مثل Yahoo Finance chart feed غير رسمية.
- تُحفظ اللقطات لكل حساب مستخدم في الجداول ذات `user_id` وسياسات RLS؛ ليست خدمة تغذية سوق مركزية مشتركة ولا يُفترض استمرار التحديث التلقائي دون فتح التطبيق أو طلب تحديث الأسعار.

## تطبيق الهاتف (PWA)

النشر على Vercel يقدّم تطبيق ويب قابلًا للتثبيت، وليس ملف APK أصليًا أو نشرًا تلقائيًا في Google Play.
- Android: افتح رابط الموقع في Chrome ثم اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".
- iPhone/iPad: افتح الموقع في Safari ثم مشاركة ← Add to Home Screen.
- يتطلب التثبيت اتصال HTTPS. Service Worker يخزّن غلاف التطبيق فقط؛ لا يخزّن استجابات API أو بياناتك المالية في cache.

## المصادر وحدود البيانات

- Gold API: السعر الفوري XAU/XAG وبيانات المعادن/أصول محددة.
- Frankfurter: أسعار الصرف اليومية المرجعية.
- CoinGecko: الرموز الرقمية الأخرى تتطلب `COINGECKO_API_KEY` كمتغير Sensitive في Vercel.
- Yahoo Finance chart feed: أسعار الأسهم عبر نقطة بيانات غير رسمية وقد تتغير أو تتوقف.

الأسعار استرشادية وليست أوامر شراء أو بيع أو تحويل أموال. تحقق من المصدر وتاريخ السعر قبل اتخاذ أي قرار.

## التشغيل المحلي

المتطلبات: Python 3.11+ وملف `.env` محلي غير مرفوع إلى GitHub.
1. انسخ `.env.example` إلى `.env` وأدخل إعدادات Supabase.
2. ثبّت المتطلبات: `pip install -r requirements.txt`.
3. شغّل: `uvicorn main:app --reload`.
4. افتح `http://127.0.0.1:8000`.

لا تضع مفاتيح حقيقية في `.env.example` أو في مستودع GitHub.
