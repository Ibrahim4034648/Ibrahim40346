# WALLET OS

واجهة عربية RTL لإدارة السجل المالي، بواجهة داكنة فاخرة بلون ذهبي، ورسوم تفاعلية، وإضافة/تعديل/حذف العمليات. تشمل لوحة القيادة وأقسام الدخل والمصروفات والالتزامات والادخار والاستثمار والحسابات والميزانيات والتقارير والمساعد والإعدادات.

## نشر الواجهة
1. اربط المستودع بـ Vercel واختر مجلد الجذر wallet-os.
2. انشر المشروع.
3. لا تعتبر الاتصال السحابي فعالًا قبل إعداد Supabase وإكمال اختبارات المصادقة والمزامنة.

## Supabase
1. أنشئ مشروع Supabase جديدًا في المؤسسة التي تختارها.
2. نفّذ ملف supabase/schema.sql في SQL Editor.
3. انسخ عنوان المشروع ومفتاح publishable/anon إلى config.js.
4. أعد النشر. لا تضع مفتاح service_role في المتصفح.
5. اختبر إنشاء الحساب وتسجيل الدخول وسياسات RLS بحسابين منفصلين.

## Ollama
Ollama ليس نموذجًا مدمجًا داخل Vercel؛ يحتاج إلى خادم منفصل يعمل عليه Ollama ويمكن الوصول إليه عبر HTTPS. اضبط في Vercel Environment Variables المتغيرين OLLAMA_BASE_URL (عنوان خدمة Ollama الآمن) وOLLAMA_MODEL (اسم النموذج الذي نزّلته فعلًا على الخادم). لا تعرّض Ollama للإنترنت دون مصادقة/بوابة وصول وحدود استخدام. بعد إضافة المتغيرات، أعد النشر واختبر /api/chat. لم يُثبّت النموذج أو يُنزّل تلقائيًا على خادم خارجي من هذا المستودع.

## حدود النسخة الحالية
- النسخة التجريبية تستخدم localStorage على الجهاز.
- أسعار الصرف تقريبية وثابتة وليست أسعارًا لحظية.
- وحدات الأهداف والقروض والاستثمارات والميزانيات ما زالت واجهات أولية وليست سجلات محاسبية مستقلة.
- راجع العمليات والنتائج قبل استخدامها لاتخاذ قرارات مالية حقيقية.
